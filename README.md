## 👨‍💻 About Me

I'm a Frontend Developer based in Buenos Aires, Argentina, focused on **Angular, TypeScript and modern web development**.

I have professional experience developing and maintaining enterprise applications for clients in the insurance and financial sectors.

- Developing user interfaces and implementing new features.
- Improving existing applications through refactoring and modularization.
- Integrating frontend applications with REST APIs.
- Working with relational databases and data validation.
- Working with Java and Spring Boot for backend integration and development.

I'm passionate about writing clean code, building maintainable applications and continuously improving my development skills.
